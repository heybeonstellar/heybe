## Contract tests

26 tests run in CI (`.github/workflows/ci.yml`) and locally:

```bash
cd contracts && stellar contract build && cargo test
```

- `heybe-account` (19): Path A payments, control moving with the NFT, strangers and previous owners rejected, other NFTs held and sent, self-transfer and self-ownership guards, burned NFT, lock rules, and Path B with real CAP-71 auth entries (`set_auths`): owner delegate accepted, non-owner, extra and missing delegates rejected, delegation follows the NFT, lock respected.
- `heybe-registry` (7): deterministic addresses, permissionless single creation, `created` event, funds sent before deployment, end-to-end flow and Path B against the compiled account wasm.
